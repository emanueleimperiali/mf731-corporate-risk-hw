# MF 731 — Corporate Risk Management (Fall 2026)

Code for the homework assignments of MF 731, per the syllabus submission
guidelines (code hosted on GitHub, linked from the PDF write-up).

Each homework lives in its own folder, named after the assignment PDF.

## Homeworks

| Folder | Assignment | Description |
|---|---|---|
| [`hw02_vol_calc/`](hw02_vol_calc/) | `02_vol_calc_pub.pdf` | Volatility calculations: horizon scaling, Black-Scholes implied vol, EWMA and GARCH(1,1) updates, long-term GARCH volatility and forecast convergence. |

## Requirements

Each script uses only the Python standard library unless a folder's own
README says otherwise. Run with Python 3.9+.
